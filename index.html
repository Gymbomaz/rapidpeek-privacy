2. Cosa fa l'app

Rapid Peek è un file manager: permette di sfogliare, aprire, rinominare, spostare, copiare, comprimere/estrarre ed eliminare i file presenti sulla memoria del tuo dispositivo (archivio interno, schede SD, chiavette USB).

3. Accesso ai file

Per funzionare, l'app richiede il permesso di accesso a tutti i file del dispositivo (MANAGE_EXTERNAL_STORAGE su Android 11+, READ/WRITE_EXTERNAL_STORAGE sulle versioni precedenti). Questo permesso è necessario perché l'app è, per sua natura, uno strumento di gestione file generico — a differenza di un'app che accede solo alle proprie foto o ai propri documenti.

I tuoi file restano sul tuo dispositivo. Rapid Peek non carica, non trasmette e non condivide il contenuto dei tuoi file con noi o con terze parti. Non abbiamo server propri e non riceviamo mai una copia di ciò che l'app mostra o elabora: tutte le operazioni (ricerca, anteprima, compressione, estrazione, ecc.) avvengono localmente sul tuo dispositivo.

4. Pubblicità (Google AdMob)

L'app mostra pubblicità tramite Google AdMob (banner e interstitial) per sostenerne lo sviluppo gratuito. Per farlo:

  • Usiamo l'identificativo pubblicitario del dispositivo (Advertising ID), che Google utilizza per mostrare annunci — personalizzati o meno a seconda del consenso che dai.
  • Alla prima apertura, se richiesto dalla tua area geografica (es. Unione Europea/Regno Unito), ti viene mostrato un modulo di consenso (Google User Messaging Platform — UMP) per scegliere se accettare annunci personalizzati, non personalizzati, o gestire le tue preferenze. Puoi cambiare idea in qualsiasi momento dalle impostazioni dell'app/del dispositivo o ripetendo il modulo di consenso.
  • Google (e i suoi partner pubblicitari) possono raccogliere dati secondo le proprie informative: Informativa sulla privacy di Google · Come Google usa i dati dei partner.

Non abbiamo accesso diretto ai dati raccolti da Google per la pubblicità: la raccolta e l'elaborazione avvengono secondo le policy di Google, non le nostre.

5. Dati che NON raccogliamo

Rapid Peek non richiede la creazione di un account, non raccoglie il tuo nome, email, numero di telefono o altri dati identificativi, e non include strumenti di analisi (analytics) propri. Non vendiamo né condividiamo dati con terze parti al di fuori di quanto necessario al funzionamento di Google AdMob descritto sopra.

Gymbomaz Apps declina ogni responsabilità per la perdita o il danneggiamento di file, documenti o dispositivi derivante dall'uso dell'app, incluso — a titolo di esempio — l'eliminazione accidentale di file, l'uso scorretto delle funzioni di sovrascrittura, o malfunzionamenti del dispositivo non imputabili all'app. Ti consigliamo di mantenere sempre una copia di backup dei tuoi file importanti.
